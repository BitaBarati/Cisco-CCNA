# Cisco CCNA

A structured technical knowledge base for Cisco networking and CCNA studies, containing practical configuration guides, networking concepts, and troubleshooting notes.

## Topics

- Networking Fundamentals
- OSI and TCP/IP Models
- IP Addressing and Subnetting
- Ethernet and Switching
- VLANs and Trunking
- Spanning Tree Protocol (STP)
- Routing and Routing Protocols
- Network Services
- Access Control Lists (ACLs)
- Network Security
- Wireless Networking
- Network Troubleshooting

## Documentation Standards

The documentation focuses on:

- Concise, technically accurate explanations
- Cisco IOS configuration commands
- Practical lab examples
- Configuration verification
- Troubleshooting procedures
- Common errors and implementation notes

All documents are written in English using GitHub Flavored Markdown and organized into topic-specific directories.

## Repository Structure

The repository is organized into separate directories based on networking topics. The structure will evolve as new documentation is added.

## Scope

This repository is dedicated to Cisco networking, CCNA topics, and practical networking skills.

Windows Server, Active Directory, and related Windows infrastructure documentation are maintained in a separate repository.

## Purpose

To build a well-organized technical reference for reviewing networking concepts, practicing Cisco configurations in lab environments, and developing professional networking skills.
